Bienvenue dans la base de prompts photographiques ultra-réalistes pour le site 
du Maître Marabout Aziman.

Tous les prompts ont été rédigés sur mesure en s'inspirant des recherches les 
plus pertinentes et populaires sur Google Images et Pinterest avec l'expression :
"marabout africain [theme / service / produit]"

Chaque élément bénéficie de 3 prompts distincts et complémentaires :
- Prompt 1 : Ambiance rituelle d'autel / Cérémonie immersive au sanctuaire
- Prompt 2 : Gros plan macro sur les objets rituels, cadenas, cauris, herbes
- Prompt 3 : Mise en situation réaliste (consultation à Paris / client apaisé)

Total : 83 fiches détaillées x 3 prompts = 249 prompts uniques prêts à l'emploi.

MODE D'EMPLOI DES PROMPTS AVEC LES INTELLIGENCES ARTIFICIELLES
--------------------------------------------------------------------------------

1. MIDJOURNEY (v6.1 recommande) :
   - Ouvrez Discord, tapez : /imagine prompt:
   - Collez le prompt du fichier .txt
   - Ajoutez le suffixe recommandé : --v 6.1 --style raw

2. FLUX.1 (Schnell, Dev ou Pro sur Fal.ai, Replicate ou ComfyUI) :
   - Collez le texte du prompt directement dans l'invite.
   - Réglez les dimensions selon le format :
     * 16:9 = 1344 x 768 pixels
     * 4:3  = 1152 x 864 pixels
     * 1:1  = 1024 x 1024 pixels

3. DALL-E 3 (ChatGPT Plus) :
   - Collez le prompt en débutant par :
     "Photo réaliste de haute qualité prise avec un iPhone 17 Pro Max : [PROMPT]"
